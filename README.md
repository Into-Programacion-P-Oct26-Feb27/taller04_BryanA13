* Problema01
> Se requiere el desarrollo de un programa en Java para automatizar el seguimiento de las finanzas de una familia. El objetivo es calcular la carga económica total que representa la descendencia. El programa debe ser capaz de solicitar y registrar el nombre de cada uno de los tres hijos, junto con su respectivo monto de gasto mensual promedio. Una vez que se tienen estos datos de entrada, la aplicación deberá calcular el Gasto Total Consolidado, sumando los gastos individuales de los tres hijos. Finalmente, la herramienta debe generar un informe de salida que presente de manera clara el nombre de cada hijo con su gasto asociado y el monto final del Gasto Total Consolidado que el padre de familia debe cubrir mensualmente.
---

* Problema03
> Generar un programa en Java que permita calcular y mostrar el valor de la planilla de teléfono de un casa. Se debe ingresar el costo por minutos, el número de minutos consumidos en el mes, la dirección del domicilio, el nombre completo del dueño de la línea telefónica. Finalmente presentar el siguiente reporte

```
Reporte:
Nombres completos: Luis Alberto Carvajal Ludeña
  Dirección: Calle primera entre segunda y décima
Costo por minuto: $1.5
  Número de minutos consumidos: 50
    Valor a cancelar: $75
```

* Problema04
>Como parte del equipo de "Tech-Build Solutions", su tarea fundamental es garantizar la precisión en la cotización de nuestros productos. Se requiere que desarrollen un programa en Java capaz de simular el proceso de cálculo del costo final de producción de nuestra estación de trabajo estándar, el modelo "Quantum-Core X1". El programa deberá solicitar al usuario el costo individual de los cuatro componentes críticos: la Unidad Central de Procesamiento (CPU/Torre), el Dispositivo de Salida Visual (Pantalla), el Dispositivo de Entrada Principal (Teclado) y el Dispositivo de Interacción (Ratón). Una vez obtenidos estos datos, el programa debe calcular el Costo Base Total (suma de los cuatro componentes). Posteriormente, deberá aplicar un factor de Costos Operacionales (CO) del 15% sobre el Costo Base Total para cubrir gastos de ensamblaje, logística y soporte (es un valor fijo, NO ingresado por teclado). Finalmente, el programa debe generar un Reporte Detallado que muestre el costo de cada parte, el Costo Base Total, el monto exacto de los Costos Operacionales y el Costo Final de Ensamblaje para la empresa.

```
Reporte:
Nombres de cliente: Luis Alberto Carvajal Ludeña
Valores iniciales:
CPU:  $ 600.0
Teclado: $ 20.0
Ratón: $ 15.0
Pantalla: $ 300.0

Costo base: $ 935
Costo adicional del 15%: 140.25
Costo final: $ 1075.25
```
