# Taller-04-ingreso-de-datos

## Taller 04: desarrollo de programas secuenciales en Java mediante ingreso de datos, operaciones aritméticas y generación de reportes.

### Listado de problemáticas
- Por cada problemática generar un proyecto en Netbeans. El proyecto ubicarlo en la carpeta correspondiente
- Todos los valores solicitados en los enunciados deben ingresarse mediante teclado.
----

#### Problema01

Una universidad necesita llevar un control de los recursos económicos destinados al desarrollo de tres proyectos académicos durante el semestre.

Para facilitar esta tarea, se requiere desarrollar un programa en Java que permita registrar el **nombre de cada uno de los tres proyectos**, junto con el monto correspondiente a sus gastos mensuales.

Una vez ingresada la información, el programa deberá calcular el **gasto mensual total**, mediante la suma de los valores registrados para los tres proyectos.

Finalmente, la aplicación deberá generar un reporte que presente de manera organizada el nombre de cada proyecto, su respectivo gasto mensual y el monto total que la universidad destina mensualmente al financiamiento de estas actividades.

> Consideraciones

- Los nombres y gastos de los tres proyectos deben ingresarse mediante teclado.
- Los gastos deben manejarse como valores numéricos con decimales.
- Los valores monetarios deben presentarse con dos cifras decimales.

> Ejemplo de ejecución

**Datos ingresados:**

```text
Ingrese el nombre del proyecto 1: Desarrollo de software
Ingrese el gasto mensual: 350.50

Ingrese el nombre del proyecto 2: Inteligencia artificial
Ingrese el gasto mensual: 420.75

Ingrese el nombre del proyecto 3: Seguridad informática
Ingrese el gasto mensual: 280.25
```

**Reporte generado:**

```text
CONTROL DE GASTOS DE PROYECTOS
Proyectos:                             
-------------------------------
1. Desarrollo de software: $350.50
2. Inteligencia artificial: $420.75
3. Seguridad informática: $280.25
-------------------------------
GASTO MENSUAL TOTAL: $1051.50
```

#### Problema03

Una empresa de telecomunicaciones requiere desarrollar un programa en Java que permita generar la planilla mensual del servicio telefónico residencial de sus clientes.

La empresa cobra por los minutos de llamadas realizados durante el mes. Cada cliente tiene una tarifa por minuto que determina el valor de su consumo.

El programa debe permitir generar un reporte similar al siguiente:

```text
==========================================================
PLANILLA DE SERVICIO TELEFÓNICO
==========================================================
Titular: Luis Alberto Carvajal Ludeña
Dirección: Calle primera entre segunda y décima
----------------------------------------------------------
Costo por minuto: $1.50
Minutos consumidos: 50
----------------------------------------------------------
VALOR TOTAL A PAGAR:  $75.00
==========================================================
```

**Nota:** Los datos presentados son referenciales. El programa debe funcionar con diferentes clientes, tarifas y consumos.

#### Problema04
>Como parte del equipo de "Tech-Build Solutions", su tarea fundamental es garantizar la precisión en la cotización de nuestros productos. Se requiere que desarrollen un programa en Java capaz de simular el proceso de cálculo del costo final de producción de nuestra estación de trabajo estándar, el modelo "Quantum-Core X1". El programa deberá solicitar al usuario el costo individual de los cuatro componentes críticos: la Unidad Central de Procesamiento (CPU/Torre), el Dispositivo de Salida Visual (Pantalla), el Dispositivo de Entrada Principal (Teclado) y el Dispositivo de Interacción (Ratón). Una vez obtenidos estos datos, el programa debe calcular el Costo Base Total (suma de los cuatro componentes). Posteriormente, deberá aplicar un factor de Costos Operacionales (CO) del 15% sobre el Costo Base Total para cubrir gastos de ensamblaje, logística y soporte (es un valor fijo, NO ingresado por teclado). Finalmente, el programa debe generar un Reporte Detallado que muestre el costo de cada parte, el Costo Base Total, el monto exacto de los Costos Operacionales y el Costo Final de Ensamblaje para la empresa.

```
Reporte:
Nombres de cliente: Luis Alberto Carvajal Ludeña
Valores iniciales:
CPU:  $ 600.0
Teclado: $ 20.0
Ratón: $ 15.0
Pantalla: $ 300.0

Costo base: $ 935
Costo adicional del 15%: 140.25
Costo final: $ 1075.25
```

* Problema05
> Una empresa ofrece a sus clientes la contratación de cuatro servicios digitales: Netflix, YouTube Premium, Dropbox y Spotify. Con el objetivo de incentivar las contrataciones, la empresa ha establecido las siguientes promociones:
  * Netflix: descuento del 23 % sobre su precio mensual.
  * YouTube Premium: descuento del 23 % sobre su precio mensual.
  * Dropbox: descuento del 45 % sobre su precio mensual.
  * Spotify: no tiene descuento.

> Desarrolle un programa en Java que permita ingresar por teclado el nombre del cliente y el precio mensual original de cada uno de los cuatro servicios. El programa debe calcular: el valor del descuento correspondiente a cada servicio; el precio final de cada servicio después de aplicar su descuento; el costo mensual total de los cuatro servicios sin descuentos; el ahorro mensual total obtenido por el cliente. el valor total que deberá pagar mensualmente el cliente después de aplicar las promociones.
